# Security policy · Politique de sécurité

**[English](#reporting-a-vulnerability)** · **[Français](#signaler-une-faille-de-sécurité)**

## Reporting a vulnerability

Please **do not open a public issue** for a security vulnerability.

Use GitHub's private reporting: the repository's **Security** tab →
**Report a vulnerability**. The report is only visible to the project maintainers.

If possible, include the affected version (Settings → About), the operating system,
steps to reproduce, and the estimated impact. You will get a reply as soon as
possible; the fix is released in a new version, and the vulnerability is then
described in its release notes.

Only the latest released version receives security fixes.

## Signaler une faille de sécurité

Merci de **ne pas ouvrir de ticket public** pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt →
**Report a vulnerability**. Le message n'est visible que des responsables du projet.

Indiquez si possible la version concernée (Réglages → À propos), le système, les étapes
pour reproduire, et l'impact estimé. Vous recevrez une réponse dès que possible ; la
correction est publiée dans une nouvelle version, puis la faille est décrite dans ses
notes de version.

Seule la dernière version publiée reçoit des correctifs de sécurité.
