the issues; security issues follow [SECURITY.md](SECURITY.md).

contribution (pull request, patch), you agree that it is licensed under these same
terms, additional permission included, and you confirm that you have the right to
do so (it is your own work, or its license allows it).

### Third-party code and dependencies

distribution on iPad. Dependencies must be under a permissive license (MIT,
Apache-2.0, BSD, ISC and similar) or the MPL-2.0.

Merci de votre intérêt pour Quayline. Les signalements de bogues et les suggestions
sont les bienvenus dans les tickets ; les problèmes de sécurité suivent
[SECURITY.md](SECURITY.md).

Quayline est distribué sous [GNU GPL version 3 ou ultérieure](LICENSE), avec une
[permission additionnelle](LICENSE-APPSTORE) pour les boutiques d'applications d'Apple.
En proposant une contribution (pull request, correctif), vous acceptez qu'elle soit
distribuée aux mêmes conditions, permission additionnelle comprise, et vous confirmez
en avoir le droit (c'est votre propre travail, ou sa licence le permet).

### Code tiers et dépendances

Du code sous GPL sans cette permission ne peut pas être ajouté : il empêcherait la
distribution sur iPad. Les dépendances doivent être sous une licence permissive (MIT,
Apache-2.0, BSD, ISC et semblables) ou sous MPL-2.0.
